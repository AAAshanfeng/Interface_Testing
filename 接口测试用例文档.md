# 接口测试用例文档

## 模块一：用户登录接口（POST /auth/login）

**URL：https://dummyjson.com**

| 编号 | 用例名称         | 模块 | 优先级 | 请求方法 | URL                    | 请求头                        | 请求体（请求数据）                   | 预期结果                                        |
| ---- | ---------------- | ---- | ------ | -------- | ---------------------- | ----------------------------- | ------------------------------------ | ----------------------------------------------- |
| TC01 | 正常登录         | 登录 | P0     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys, password=emilyspass | 状态码200，返回accessToken和refreshToken        |
| TC02 | 密码错误         | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys, password=错误密码   | 状态码400，提示"Invalid credentials"            |
| TC03 | 用户名为空       | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username="", password=emilyspass     | 状态码400，提示"Username and password required" |
| TC04 | 密码为空         | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=emilys, password=""         | 状态码400，提示"Username and password required" |
| TC05 | 账号密码都不存在 | 登录 | P1     | POST     | {协议+域名}/auth/login | Content-Type:application/json | username=aaaaaaa, password=aaaaaaa   | 状态码400，提示"Invalid credentials"            |



## 模块二：商品接口（/products）—— CRUD完整覆盖

**URL：https://dummyjson.com**

| 编号 | 测试点       | 接口                     | 方法   | 输入                 | 预期结果                       |
| ---- | ------------ | ------------------------ | ------ | -------------------- | ------------------------------ |
| TC06 | 查询单个商品 | {协议+域名}/products/1   | GET    | id=1                 | 状态码200，返回id=1的商品详情  |
| TC07 | 新增商品     | {协议+域名}/products/add | POST   | title="我的测试商品" | 状态码201，返回新增的商品数据  |
| TC08 | 更新商品     | {协议+域名}/products/1   | PUT    | title="修改后的标题" | 状态码200，title字段已更新     |
| TC09 | 删除商品     | {协议+域名}/products/1   | DELETE | id=1                 | 状态码200，isDeleted字段为true |



## 模块三：接口鉴权/登录关联测试（GET /auth/me）

**URL：https://dummyjson.com**

| 编号 | 测试点            | 输入                             | 预期结果                        |
| ---- | ----------------- | -------------------------------- | ------------------------------- |
| TC10 | 携带正确token访问 | Authorization: Bearer 有效token  | 状态码200，返回当前登录用户信息 |
| TC11 | 携带错误token访问 | Authorization: Bearer 乱写的字符 | 状态码401，鉴权失败             |
| TC12 | 不携带token访问   | 无Authorization header           | 状态码401，鉴权失败             |
